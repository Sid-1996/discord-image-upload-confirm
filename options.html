Discord 圖片上傳 - 選項

使用前請先知道

  • 圖片會被上傳到第三方圖床,不是 Discord。本擴充與這些服務沒有任何關係。
  • 任何人只要拿到圖片網址就能看到圖片,請不要上傳不想讓別人看到的內容。
  • 每次上傳前都會跳出確認視窗,按「取消」不會上傳任何東西。

攔截範圍

只有在你指定的頻道或伺服器裡,貼上或拖曳圖片才會被攔截;其他地方 Discord 照常運作。

    清單是空的。到 Discord 頁面點工具列上的擴充圖示,就能把目前的頻道或伺服器加入清單。
    在 Discord 網頁版的網址列複製目前頻道的網址貼上即可。私訊的網址是 /channels/@me/…,加入「整個伺服器」代表所有私訊。
    討論串與論壇貼文有自己的 ID,不會被「頻道」規則涵蓋;被限制的伺服器建議直接加入「整個伺服器」。

    圖源 1:Uguu(不需要帳號)

    • 匿名上傳,不需要註冊,也不用設定。
    • 檔案是臨時保存,多久刪除由 Uguu 決定,到期後 Discord 裡的圖片會失效。
    • 官網:https://uguu.se

    圖源 2:ImgLink(需要自己註冊)

    ImgLink 的 API 上傳需要 API Key,請自行註冊帳號後建立:

    1. 到官網註冊免費帳號:https://imglink.cc/register
    2. 登入後到後台(Dashboard)的 API Keys 區塊,按 Generate New Key 建立金鑰:https://imglink.cc/dashboard
    3. 把金鑰貼在下面的欄位並儲存。

    關於隱私(只有知道網址的人看得到)

    • ImgLink 的圖片可設為「私密(private)」。依官方說明,私密圖片只能透過網址存取,不會被搜尋或出現在公開頁面。
    • 圖片預設可能是公開的。本擴充無法替你設定私密,請在 ImgLink 的帳號後台自行把圖片設為私密(介面以官網為準)。
    • 私密圖片能不能在 Discord 正常顯示預覽,請先自己測試一張。

    官網:https://imglink.cc ・API 文件:https://imglink.cc/wiki/api-docs

    金鑰只存在這個瀏覽器的擴充儲存空間,由背景程式使用,不會傳給 Discord 頁面。 只有選擇 ImgLink 上傳時才需要。
